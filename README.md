## 🛠️ Troubleshooting Common Issues

### My note disappeared
- Check if noty is still running (look for its icon in the menu bar).
- Try restarting noty.
- Your note content is stored locally, so try re-opening noty to see if it returns.

### noty won't open
- Ensure you have a compatible system (macOS 12 or later is recommended).
- Try restarting your computer.
- Re-download noty from the link above.

### Notes overlap each other
- Simply drag each note to a different spot on your screen edge.
- You can also use multiple edges: put some notes on the left and others on the right.

### I can't read my note text
- Some notes might automatically shrink when there's too much text.
- Click on a note and use the zoom or font controls (if available).
- Or, you can shorten the note text.

## 💡 Frequently Asked Questions

### Is noty free to use?
Yes, noty is completely free. No subscriptions, no hidden costs.

### Do I need an internet connection?
No. noty works entirely offline. Your notes are stored on your hard drive.

### Can I sync notes between my computers?
noty does not include cloud sync. To transfer notes, you'd need to manually recreate them on another device.

### Is noty safe for sensitive information like passwords?
While noty encrypts notes, it's not designed as a password manager. For highly sensitive data like passwords, consider a dedicated password manager app.

### Will noty slow down my computer?
No. noty is designed to use minimal system resources, even with many notes open.

### Can I use noty on Windows or Linux?
noty is designed for macOS only. For Windows or Linux, search for similar sticky note apps for those systems.
